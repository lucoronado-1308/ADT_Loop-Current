# ADT_Loop-Current

# Loop Current Identification from Absolute Dynamic Topography

This repository contains MATLAB workflows developed for the identification and visualization of the Loop Current in the Gulf of Mexico using Absolute Dynamic Topography (ADT) data.

The analysis includes:
- processing of NetCDF oceanographic datasets,
- spatial subsetting from global products to the Gulf of Mexico region,
- monthly averaging (2002–2022),
- identification of the Loop Current using the 28 cm ADT contour,
- visualization and mapping workflows.

The repository includes:
- NetCDF examples,
- MATLAB processing scripts,
- regional subsets,
- figure generation routines.

## Main tools

- MATLAB
- NetCDF data handling
- Geospatial processing
- Oceanographic visualization

## Workflow summary

1. Import global ADT datasets
2. Spatially subset the Gulf of Mexico
3. Compute monthly mean fields
4. Identify the 28 cm contour associated with the Loop Current
5. Generate maps and visual outputs

## Notes

This repository is intended as a technical and methodological example for oceanographic data analysis workflows.
